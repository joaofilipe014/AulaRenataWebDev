O que é Git?

O Git é um sistema de controle de versão usado para registrar e acompanhar as alterações feitas em arquivos de um projeto, principalmente projetos de programação. Com o Git, o desenvolvedor consegue salvar versões do código ao longo do tempo. Cada versão salva é chamada de commit. Isso permite voltar para versões anteriores, comparar mudanças e entender o histórico do projeto. O Git também ajuda no trabalho em equipe, porque várias pessoas podem trabalhar no mesmo projeto, criar alterações separadas e depois juntar tudo de forma organizada.

Exemplos

Imagine que você está criando um site. Primeiro você faz a página inicial, depois adiciona um menu, depois muda as cores e depois corrige um erro. Com o Git, você pode salvar cada uma dessas etapas. Assim, se alguma alteração der problema, você consegue voltar para uma versão anterior do projeto.

Para que serve o Git?

O Git serve para:

  • controlar versões de um projeto;
  • salvar o histórico das alterações;
  • voltar para versões anteriores;
  • comparar mudanças no código;
  • trabalhar em equipe;
  • organizar melhor o desenvolvimento.
