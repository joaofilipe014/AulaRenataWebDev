GitHub nos meus estudos

O GitHub é uma plataforma que estou usando para guardar meus projetos e acompanhar minha evolução nos estudos. Mesmo em projetos simples, ele ajuda a deixar tudo mais organizado.

Para quem está estudando Engenharia de Software, o GitHub também ajuda a criar o costume de salvar versões do código e trabalhar de uma forma mais parecida com o mercado.

Site oficial: GitHub

Relação com o back-end

Meu foco principal nos estudos é o desenvolvimento back-end. Essa área envolve a criação de APIs, regras de negócio, banco de dados, autenticação e organização da parte interna dos sistemas.

Quando faço projetos com Java, Spring Boot ou banco de dados, o Git ajuda a salvar cada etapa do desenvolvimento. Assim, fica mais fácil saber o que foi feito e corrigir erros quando alguma coisa para de funcionar.

  • Salvar alterações em projetos Java.
  • Controlar mudanças em arquivos SQL.
  • Organizar commits por etapa do projeto.
  • Enviar projetos para o GitHub.
  • Acompanhar minha evolução nos estudos.

Comandos básicos que eu uso

Alguns comandos aparecem bastante durante os estudos. Eles são simples, mas ajudam muito na organização do projeto.

  1. git init: inicia o Git na pasta do projeto.
  2. git status: mostra os arquivos modificados.
  3. git add .: prepara os arquivos para salvar.
  4. git commit -m "mensagem": salva uma versão.
  5. git push: envia o código para o GitHub.

Exemplo em um projeto de API

Em um projeto back-end, eu posso começar criando uma entidade, depois o repository, o service e o controller. Cada parte pode ser salva com um commit diferente.

Isso ajuda porque, se eu errar alguma coisa, consigo olhar o histórico e entender melhor onde o problema começou.

  • Criar uma entidade.
  • Criar um repository.
  • Criar um service.
  • Criar um controller.
  • Testar e salvar as alterações.

Por que aprender isso agora?

Aprender Git e GitHub durante a faculdade é importante porque são ferramentas usadas em muitos projetos reais. Mesmo eu ainda estando em fase de aprendizado, já consigo praticar uma organização melhor nos meus códigos.

Como quero focar em back-end, preciso me acostumar com projetos maiores, que possuem várias classes, pacotes, banco de dados e arquivos de configuração.

Dica de estudante

Uma coisa que percebi é que não adianta aprender Git só na teoria. O melhor jeito é usar em todos os projetos, mesmo nos exercícios pequenos da faculdade.

Meus objetivos

Meus objetivos estudando Git, GitHub e back-end são melhorar minha organização e criar projetos cada vez mais completos.

  1. Aprender melhor os comandos do Git.
  2. Usar GitHub nos projetos da faculdade.
  3. Praticar Java e Spring Boot.
  4. Estudar banco de dados.
  5. Criar APIs mais organizadas.
